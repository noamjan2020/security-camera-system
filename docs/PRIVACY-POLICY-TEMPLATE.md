# HomeGuard privacy policy template

**Replace bracketed fields before distribution.**

HomeGuard is a personal security-camera application operated by the account owner. Camera frames and face-recognition embeddings are processed locally on the owner’s Windows PC. Continuous video and biometric embeddings are not uploaded by default.

When remote features are enabled, HomeGuard may upload event screenshots, event metadata, device identifiers, push-notification tokens, short user-recorded voice messages, command receipts and diagnostic records to the owner’s configured cloud services. Media is stored in private buckets and deleted according to the configured retention period.

HomeGuard does not sell personal data, include advertising trackers, secretly record microphone audio, or allow microphone recording without an explicit user action. Face recognition is imperfect and is used only as an alert-filtering convenience.

Users can pause the camera, activate a persistent local emergency disable, delete events, revoke devices, sign out, uninstall applications and request account deletion. Diagnostic logs may contain timestamps, camera/device names, event IDs and network/error metadata, but should not intentionally contain passwords or authorization tokens.
